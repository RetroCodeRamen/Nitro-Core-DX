# Documentation

Two books, plus this folder.

- [`../NITRO_CORE_DX_MANUAL.md`](../NITRO_CORE_DX_MANUAL.md) — the
  **Nitro-Core-DX Manual**. Playing the console, the hardware, the
  Dev Kit.
- [`../CORELX_PROGRAMMING_MANUAL.md`](../CORELX_PROGRAMMING_MANUAL.md)
  — the **CoreLX Programming Manual**. The language, the builtins, and
  how Sprite Lab / Tilemap Lab / Sound Studio land in your source.
- [`manual_examples/`](manual_examples/) — the demo programs the
  programming manual compiles on every test run.

Everything else that used to live under `docs/` — hardware drafts,
FPGA notes, planning, old language charters, debugging internals —
is in [`archive/`](archive/). Treat it as history. The two manuals
above are what an end user needs.
